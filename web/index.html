Importar dados

Extrato bancário ou fatura — aceita OFX, CSV, Excel e PDF.

📤 Enviar arquivo

Formatos aceitos: OFX (o extrato que o banco baixa), CSV, Excel (.xlsx / .xls) e PDF. O app lê o arquivo, sugere categorias e marca o que já foi importado antes, para nada entrar em dobro.

📋 Como o arquivo deve ser

Para importar sem erro, use colunas com estes nomes (a ordem não importa):

ColunaObrigatóriaExemplo
DataSim24/07/2026
DescriçãoSimSupermercado Bom Preço
ValorSim-850,00
TipoOpcionalreceita / despesa
CategoriaOpcionalAlimentação

Sem a coluna Tipo: valor negativo vira despesa e positivo vira receita. Sem Categoria, o app sugere pela descrição.

🎨 Aparência — foto de fundo

Escolha uma foto sua para aparecer bem discreta no fundo do app. Fica salva só neste aparelho.

⚠️ Apagar todos os dados

Remove todos os lançamentos, cartões, contas, orçamentos e metas de toda a família. As categorias são mantidas. Use para começar do zero com os dados reais. Esta ação não pode ser desfeita.
